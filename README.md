# 2FA Manager

2FA Manager is a private, client-side TOTP authenticator for managing two-factor authentication codes in the browser.

## Development

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```

## Tests

```bash
pnpm test
```

## Quality Checks

```bash
pnpm check
```

## Deploy to Cloudflare Workers

This project uses the Cloudflare Vite plugin and `wrangler.jsonc`.

```bash
pnpm deploy
```
